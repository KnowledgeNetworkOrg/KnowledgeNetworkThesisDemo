**How it works.** The map used to fit each domain name inside its own region and never look at its neighbours. There is now a second pass at the top zoom level (the domain names). It walks the names in list order and keeps a name only if it doesn't meet one already kept. A dropped name is not drawn or reserved, so a walk pin no longer steers around it, and the hover tooltip still shows it. The wrapping and shrinking logic is untouched, and so are the module names and the faint parent names shown at deeper levels. The rail still starts closed, since the card only asked to revisit that.

**What changed**
- **`src/model/labelfit.ts`:** added `regionLabelBox`, which measures the box a drawn domain name takes up, and `keepClearOfEarlier`, which does the keep-or-drop walk. Boxes that only touch along an edge don't count as meeting, matching the browser driver's test.
- **`src/instruments/MapView.tsx`:** the domain-name fit at level 0 now runs the gate and stores only the survivors. The name's font weight is one shared constant so the drawn text and its measured box can't drift. I also rewrote the "closed at first" comment on the rail so it no longer describes the collision as open.
- **`src/model/labelfit.test.ts`:** tests for both new functions. They cover an overlap dropping the later name, clear names all staying, a dropped name not blocking a third, list order deciding which goes, and touching edges not counting.
- **`tools/studio-spike/browsertest-mapconnections.mjs`:** the domain-name check now runs twice. With the rail closed it asserts every domain is still named and none overlap. With the rail opened from its corner it asserts no two drawn names overlap and logs which were dropped. It then logs (without asserting) any module-name overlaps at the next level, rail closed and open. If those collide, that is a follow-up card.

Assumptions: I took "L0" to mean the domain names, which the level picker labels "L1" since #336. "Later" means later in the domain list, which is also draw order, and the later name is dropped outright rather than shrunk or ghosted. The gate runs at the level's resting zoom, like the existing fit. The box height comes from the font's declared metrics in `tokens/fonts.css` (about 0.95 of the font size above the baseline, 0.42 below), not measured in a browser, because I couldn't run one. If the first browser-driver run shows the box too tall (dropping a name that fits with the rail closed) or too short (still overlapping), those two numbers in `labelfit.ts` are what to adjust.
